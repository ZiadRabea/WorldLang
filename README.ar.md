WorldLang هو مترجم مفتوح المصدر مبني بلغة Python يزيل حواجز اللغة في البرمجة. بدلاً من حفظ الكلمات المفتاحية الإنجليزية، تكتب الكود باستخدام بنية لغتك المحلية. يدعم WorldLang خط أنابيب متعدد اللغات للتنفيذ، بالإضافة إلى اكتشاف اللغة تلقائيًا وترجمة الكود المصدري بين اللغات المدعومة عبر بنية مخصصة: Lexer → Parser → Runtime.

> **اللغات المدعومة: 31** — العربية، الأذربيجانية، الصينية، الهولندية، الإنجليزية، الفنلندية، الفرنسية، الألمانية، اليونانية، الهندية، الإندونيسية، الأيرلندية، الإيطالية، اليابانية، الكازاخية، الكورية، الكردية، اللاتفية، الملايوية، الفارسية، البولندية، البرتغالية، الرومانية، الروسية، الإسبانية، السويدية، التركية، الأوكرانية، الأردوية، الأوزبكية، الفيتنامية.

## الميزات

- **البرمجة بلغتك المحلية** — اكتب الكود باستخدام الكلمات المفتاحية للغة التي اخترتها.
- **31 حزمة لغة** مرفقة في `data/` كجداول كلمات مفتاحية بصيغة JSON.
- **اختيار هجين للغة** — اختر اللغة يدويًا أو اسمح لـ WorldLang باكتشافها تلقائيًا.
- **اكتشاف اللغة بالذكاء الاصطناعي** — اكتشف لغة الكود تلقائيًا عند عدم تحديد لغة يدويًا.
- **تنفيذ متعدد اللغات** — شغّل ملفات مكتوبة بلغات مختلفة دون الحاجة إلى تغيير اللغة النشطة يدويًا مسبقًا.
- **ترجمة كود مدمجة** — ترجم ملفات WorldLang بين اللغات المدعومة.
- **مطابقة ديناميكية للكلمات المفتاحية** — يقوم الـ lexer بمطابقة الكلمات المفتاحية المحلية مع الرموز العامة أثناء التشغيل.
- **مترجم متكامل بالكامل** — المتغيرات، الدوال، التكرار الشروطي، الحلقات، الشروط، القوائم، القواميس، والحسابات الرياضية.
- **الأجهزة والروبوتات** — اتصال تسلسلي مع وحدات التحكم الدقيقة (مثل Arduino).
- **الصوت** — تحويل النص إلى كلام والتعرف على الصوت.
- **المكتبات المدمجة** — معالجة الصور، الرسوم البيانية، الأرقام العشوائية، نظام الملفات، والمزيد.
- **الذكاء الاصطناعي التوليدي** — تكامل اختياري مع Google Gemini.
- **إدارة المكتبات والامتدادات** — جلب مكتبات وامتدادات `.world` مباشرة من الإنترنت.

## الاستخدام

يأتي المترجم كـ REPL (حلقة قراءة-تقييم-طباعة). لتشغيله:

```bash
python bin/World.py
```

يظهر موجه أوامر:

```text
World >>
```

اكتب برنامجًا واضغط Enter لتنفيذه. الأوامر الخاصة عند الموجه:

| الأمر | الإجراء |
|---|---|
| `libman` | تشغيل مدير المكتبات وتنزيل مكتبات `.world` |
| `langman` | تشغيل مدير اللغات وتنزيل حزم اللغات |
| `extman` | تشغيل مدير الامتدادات وتنزيل الامتدادات |
| `setlang` | تحديد اللغة يدويًا أو تفعيل اكتشاف اللغة تلقائيًا |
| `world()` | تشغيل ملفات WorldLang المصدرية |
| `translate()` | ترجمة كود WorldLang بين اللغات المدعومة |

يمكن تحديد اللغة يدويًا باستخدام `setlang`، أو تركها فارغة للسماح باكتشاف اللغة تلقائيًا. ويمكن تبديل أو إضافة اللغات عبر المدير `langman`.

## اكتشاف اللغة واختيارها

يدعم WorldLang نظامًا **هجينًا لاختيار اللغة**. يمكنك تحديد اللغة التي تريد استخدامها يدويًا، أو ترك اللغة غير محددة والسماح للمترجم باكتشاف لغة الكود المصدر تلقائيًا.

### اختيار اللغة يدويًا

استخدم:

```text
setlang
```

مثال:

```text
setlang -> ArabicKW
```

يحدد ذلك جدول الكلمات المفتاحية العربية كلغة نشطة.

### اكتشاف اللغة تلقائيًا

اترك وسيط اللغة فارغًا:

```text
setlang -> ""
```

يسمح ذلك لـ WorldLang باستخدام اكتشاف اللغة التلقائي. عند تفعيل هذا الوضع، يحلل WorldLang الكود المصدر ويحدد اللغة المناسبة أثناء مرحلة الـ lexing/tokenizing.

وهذا يعني أن WorldLang يمكنه تشغيل الملفات **على الفور دون تحديد اللغة مسبقًا**، كما يمكنه استيراد وتشغيل ملفات مكتوبة بلغات مختلفة من اللغات المدعومة دون تبديل اللغة يدويًا أولًا.

### وحدات اكتشاف اللغة بالذكاء الاصطناعي

يتطلب نظام اكتشاف اللغة التلقائي:

- `Keras`
- `NLTK`
- `NumPy`

يكون هذا النظام اختياريًا عند استخدام تحديد اللغة يدويًا عبر `setlang`.

## ترجمة الكود

يتضمن WorldLang الآن **مترجمًا مدمجًا للكود بين اللغات**. تتم الترجمة عبر خط أنابيب كامل:

```text
Source
   ↓
Lexer
   ↓
Translator
   ↓
DeLexer
   ↓
Translated Source
```

يتم أولًا تحليل الكود المصدر إلى تمثيلات مستقلة عن اللغة، ثم يقوم `Translator` بتحويل هذه التمثيلات إلى اللغة الهدف، وبعد ذلك يعيد `DeLexer` بناء كود WorldLang باستخدام الكلمات المفتاحية للغة الهدف.

### أمر الترجمة

```text
translate(filename.world, source_language, target_language)
```

مثال:

```text
translate("factorial.world", "English", "Chinese")
```

ينشئ WorldLang تلقائيًا ملف مصدر مترجمًا باستخدام اللغة الهدف، مثل:

```text
factorial_Chinese.world
```

وبذلك يمكنك كتابة برنامج WorldLang بلغة واحدة وتحويل الكود نفسه إلى لغة أخرى مدعومة.

## مثال على كود

**حاسبة مضروب** تكرارية مكتوبة بالكامل باستخدام الكلمات المفتاحية العربية:

```world

# حاسبة المضروب

متغير الرقم = عدد_صحيح(استقبل("أدخل رقماً"))

دالة مضروب(رقم)

    اذا رقم == 1 او رقم == 0 نفذ ارجاع 1

    ارجاع رقم * مضروب(رقم - 1)

نهاية

طباعة(مضروب(5))

```

كيف يقرأها الـ lexer:

| الكلمة المفتاحية العربية | المعنى |

|----------------|---------|

| `متغير`       | `var` |

| `دالة`        | `func` |

| `اذا`         | `if` |

| `نفذ`         | `do` |

| `ارجاع`       | `return` |

| `نهاية`       | `end` |

| `طباعة`       | `print` |

| `عدد_صحيح`    | `int` |

| `استقبل`      | `input` |

## البنية

WorldLang هو **مترجم شجري** (tree-walking interpreter) مع بنية موسعة لمعالجة الكود متعدد اللغات.

### خط أنابيب تنفيذ الكود

```text
Source Code
    ↓
اختيار اللغة / اكتشاف اللغة بالذكاء الاصطناعي
    ↓
Lexer
    ↓
Tokens
    ↓
Parser
    ↓
Abstract Syntax Tree
    ↓
Runtime
    ↓
Result
```

تسمح طبقة اكتشاف اللغة لـ WorldLang بتحديد جدول الكلمات المفتاحية المناسب تلقائيًا قبل تحليل الكود عندما لا تكون اللغة محددة يدويًا.

### خط أنابيب ترجمة الكود

```text
Source
   ↓
Lexer
   ↓
Language-Independent Representation
   ↓
Translator
   ↓
DeLexer
   ↓
Translated Source
```

تجعل هذه البنية عملية التنفيذ والترجمة مستقلة عن اللغة المستخدمة في كتابة المصدر.

### المكونات الرئيسية

| الملف / المكوّن | الدور |
|---|---|
| `World.py` | نقطة الدخول وواجهة REPL |
| `Lexer.py` | محلل رمزي؛ يطابق الكلمات المفتاحية ديناميكيًا من جدول اللغة المحددة أو المكتشفة |
| `Parser.py` | قواعد القواعد النحوية → إنشاء AST |
| `Interpreter.py` | ينفذ AST ويوفر المكتبة القياسية |
| `Tokens.py` | أنواع الرموز ومعالجة الكلمات المفتاحية |
| `Translator.py` | تحويل التمثيلات الرمزية بين اللغات المدعومة |
| `DeLexer.py` | إعادة بناء الكود المصدر باستخدام كلمات اللغة الهدف |
| `Errors.py` | أنواع الأخطاء (`IllegalChar`، `Syntax`، `Runtime`) |
| `RT_result.py` | نتائج التشغيل، السياق، وجداول الرموز |
| `datatypes/` | `Value`، `Number`، `String`، `List`، `Dict`، `Function` |
| `_builtins/` | المكتبات القياسية المدعومة بـ Python |
| `data/` | جداول الكلمات المفتاحية وموارد اللغات المتعددة |

جداول الكلمات المفتاحية هي ملفات JSON تعتمد على البيانات، مما يسمح بإضافة لغات جديدة دون إعادة كتابة القواعد الأساسية للمترجم.

## إدارة اللغة والمكتبات

يمكن لـ WorldLang جلب الموارد من الإنترنت أثناء التشغيل:

- **`langman`** — تنزيل جداول الكلمات المفتاحية للغات إضافية في `data/`.
- **`libman`** — تنزيل مكتبات `.world`.
- **`extman`** — تنزيل الامتدادات في `extensions/`.
- **`setlang`** — تحديد لغة يدويًا أو تفعيل اكتشاف اللغة بالذكاء الاصطناعي.
- **`world()`** — تشغيل ملفات WorldLang المصدرية.
- **`translate()`** — تحويل ملفات WorldLang بين اللغات المدعومة.

> تعتمد ميزات تنزيل الموارد على اتصال بالإنترنت. كما يتطلب اكتشاف اللغة التلقائي تثبيت `Keras` و`NLTK` و`NumPy`.

## المساهمة

WorldLang مفتوح المصدر ومحرك من المجتمع. مرحب بالمساهمات بأشكال متعددة:

- **مساهمو اللغات** — إضافة أو تحسين جداول الكلمات المفتاحية (`data/*_KW.json`).
- **مطورو المترجمات** — تحسين الـ lexer والـ parser والـ translator والـ DeLexer والـ runtime والمكتبة القياسية.
- **مطورو الذكاء الاصطناعي** — تحسين نماذج اكتشاف اللغة والمعالجة المسبقة.
- **مطورو الأجهزة** — توسيع التكاملات مع الأجهزة والروبوتات.
- **المختبرون** — اكتشاف الأخطاء وتحسين الموثوقية.
- **الجميع** — الإبلاغ عن المشاكل، تحسين التوثيق، ومشاركة الأفكار.

للمساهمة:

1. استنسخ المستودع.
2. أنشئ فرعًا جديدًا لتغييراتك.
3. أجرِ التغييرات وقم بالالتزام.
4. افتح طلب سحب إلى الفرع `main`.
